# GitHub Trending Repository Analyzer

This project is a Python-based tool that scrapes and analyzes trending repositories on GitHub. It identifies popular technologies and provides AI-generated insights into emerging trends. The results are displayed in an interactive web interface.

## Features

  - **Data Collection**: Fetches trending repository data from the GitHub API.
  - **Data Processing**: Cleans and organizes the data using the pandas library.
  - **Data Visualization**: Creates interactive charts with Plotly to visualize repository statistics.
  - **AI-Powered Insights**: Uses a generative AI model to summarize key trends and predict future popular technologies.
  - **Web Interface**: Presents the data in a user-friendly dashboard built with Flask.
  - **Data Persistence**: Saves the collected data in a CSV file to minimize redundant API calls.

## How It Works

1.  **Data Collection**: The script fetches data on repositories created in the last 30 days, sorted by the number of stars.
2.  **Data Caching**: It checks for a local `data.csv` file. If the file is up-to-date, it uses the cached data. Otherwise, it fetches new data from the GitHub API.
3.  **AI Analysis**: The top 10 most starred repositories are sent to a generative AI model, which provides an analysis of the current trends.
4.  **Web Dashboard**: A Flask application serves an HTML page that displays:
      - A table of the trending repositories.
      - Interactive charts showing repository stars by programming language.
      - The AI-generated summary of technology trends.

## Setup and Usage

1.  **Install Dependencies**:

    ```bash
    pip install markdown Flask requests pandas numpy plotly bs4 datetime google.generativeai colorama Flask-Frozen
    ```

2.  **Set API Key**:

      - Open the `main.py` file and replace your Google API key.

3.  **Run the script**:

    ```bash
    python main.py
    ```

    This will start a local web server, and the dashboard will open in your default web browser.

## File Descriptions

  - **`main.py`**: The main script that handles data collection, processing, AI analysis, and the web interface.
  - **`data.csv`**: The cached data of trending repositories.
  - **`build/index.html`**: The static HTML file generated by the script.
  - **`README.md`**: This file.
